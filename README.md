# AutoAlignPanels [![Sponsor](https://img.shields.io/badge/Sponsor-%E2%9D%A4-db61a2?logo=githubsponsors&logoColor=white)](https://github.com/sponsors/neuralfoundry-coder)

Keyboard-driven macOS window alignment for the front app or every visible app, with VoiceOver feedback.

**Install:** download the DMG from [Releases](https://github.com/neuralfoundry-coder/AutoAlignPanels/releases/latest), open it, choose *Install and Reopen*, and allow Accessibility access.

**Shortcuts:** `⌃⇧P/H/V` front app · `⌃⇧⌘P/H/V` all apps · `⌃⇧S` stack by app · `⌃⇧Z` undo · Magnet-style snapping: `⌃⌥←→↑↓` halves, `⌃⌥UIJK` quarters, `⌃⌥DFG`/`ERT` thirds, `⌃⌥↩` maximize, `⌃⌥⌫` restore (all configurable in Settings).

Requires macOS 13+. Free for noncommercial use under [PolyForm Noncommercial 1.0.0](LICENSE); commercial use needs permission.
